# O Saber - Aplicativo da Associação Camila

Este repositório contém o código-fonte do aplicativo "O Saber", desenvolvido para a Associação Camila. O aplicativo visa otimizar a comunicação e o acompanhamento de atividades entre a ONG, suas crianças, famílias, educadores e voluntários.

## Funcionalidades Principais

*   **Gestão de Usuários:** Perfis de Administrador, Professor, Aluno e Responsável.
*   **Comunicação:** Envio de comunicados e avisos.
*   **Acompanhamento:** Registro de frequência, agenda de eventos e lembretes.
*   **Conteúdo:** Blog com notícias e informações relevantes.
*   **Acessibilidade:** Suporte a PWA (Progressive Web App) para uso offline e instalação em dispositivos móveis.

## Configuração e Execução Local

Para configurar e executar o projeto localmente, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/Kaiqueaurelio/o-saber.git
    cd o-saber
    ```

2.  **Instale as dependências:**
    ```bash
    pnpm install
    ```

3.  **Inicie o servidor de desenvolvimento:**
    ```bash
    pnpm dev
    ```

O aplicativo estará disponível em `http://localhost:5173` (ou outra porta disponível).
