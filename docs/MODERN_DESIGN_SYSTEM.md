# Modern Design System - ONG Camila (Estilo Glassmorphism)

Baseado na referência visual fornecida, este novo design system foca em uma estética limpa, moderna e amigável.

## 🎨 Paleta de Cores (Adaptada)
- **Primary (Verde Institucional)**: `#158f3e` -> Gradiente: `linear-gradient(135deg, #158f3e 0%, #2ecc71 100%)`
- **Secondary (Laranja Institucional)**: `#e67e22` -> Gradiente: `linear-gradient(135deg, #e67e22 0%, #f39c12 100%)`
- **Background**: `#f8f9fe` (Cinza azulado muito claro)
- **Glass Card**: `rgba(255, 255, 255, 0.8)` com `backdrop-filter: blur(10px)`
- **Sidebar**: Gradiente sólido ou semi-transparente (Verde/Laranja)

## 📐 Geometria e Sombras
- **Border Radius**: `24px` para cards grandes, `16px` para botões e inputs.
- **Shadows**: `0 10px 30px rgba(0, 0, 0, 0.05)` (Sombras muito suaves e amplas).
- **Borders**: `1px solid rgba(255, 255, 255, 0.3)` para efeito de vidro.

## 🧩 Componentes Chave
1. **Sidebar Flutuante**: Com cantos arredondados e ícones minimalistas.
2. **Welcome Banner**: Card grande com gradiente e ilustração 3D (ou ícone grande).
3. **Stat Cards**: Cards brancos limpos com ícones coloridos e tipografia clara.
4. **Glass Tabs**: Navegação entre abas com efeito de vidro.

## 🖋️ Tipografia
- **Font**: Inter ou Poppins (Sans-serif moderna).
- **Headings**: Semi-bold, cores escuras mas suaves.
